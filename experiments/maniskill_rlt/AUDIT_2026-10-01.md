# 2026-10-01: Reference-Relative Critic Admission

The diagnostic selector now compares each candidate to reference ID 0 within each critic: `g_j = Q_j(candidate) - Q_j(reference)`. It admits a candidate only when `min(g) - penalty * std(g) > margin`. Invalid/duplicate candidates are masked; ties or invalid reference Q retain reference ID 0 and expose invalid-Q flags. A robot caller must handle those flags explicitly: returning the reference is not a safety certificate.

This helper is used only by `compare_residual` evaluations. The production actor, exploration and loss are unchanged. Three seeds × two target geometries × two actor types completed 1000 updates each, totaling 12 CPU fits. Targets determine diagnostic rewards only, not the selector's inputs.

On the axis task at update 300, atomic critics with ordinary min-Q argmax select actions worse than the reference on 53.91% of samples; paired margin 0.25 reduces that to 3.12%. At update 1000, the same margin gives reward -0.1797 versus -0.0052 for ordinary selection: conservatism sacrifices useful corrections. Zero margin can be worse than ordinary selection. This is neither a tuned operating threshold nor a robot safety claim.
