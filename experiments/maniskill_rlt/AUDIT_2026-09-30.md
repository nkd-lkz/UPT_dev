# 2026-09-30: Finite decisions versus continuous corrections

This audit adds an equally bounded continuous residual comparator to separate restricted exploration from discrete selection. The [full report](https://github.com/nkd-lkz/physical-self-evolution/blob/main/research/three-branch-audit-2026-09-30.md) provides curves, provenance and limitations.

## New path

`RLTBoundedResidualPolicy` retains the RLT actor/critic and executes `clip(reference + radius * tanh(raw_arm), -1, 1)`. The gripper inherits the reference; deterministic initialization equals the clipped reference. A checkpoint contract preserves radius. Entropy weight must be zero because pre-transform log probability is not the final action density.

`bounded_residual` and `atomic_decision` are mutually exclusive opt-ins. New `RLT_ATOMIC_PROFILE=residual` matches atomic pilot environment, batch, update and evaluation budgets. Both share per-component bounds, but the continuous actor can edit multiple joints and timesteps simultaneously, so their hypothesis classes differ.

## Diagnostic findings

Actual RLT loss paths learn from the same 2048 synthetic transitions and are evaluated on 256 separate contexts. Each condition uses three initializations and 1000 critic updates:

- Candidate-only data: discrete final reward 0, continuous approximately −8.03 to −8.25.
- Half continuous-action data: no material improvement.
- 300 critic-only warmup updates and actor LR 1e-4: continuous approximately −3.57 to −5.34, still degraded.

Zero is optimal reward in this analytic toy task, not robot success. The continuous actor passes supervised analytic fitting, pointing to learned-critic gradients/data support and optimization rather than representational impossibility. The task favors finite choices and does not establish general superiority. The last two conditions were exploratory follow-ups, not preregistered confirmation.

CPU regression: **204 passed, 1 skipped, 1 deselected**; excluded VideoMetadata fails in baseline as well. The atomic module passed 20 single-rank fp32 FSDP updates and checkpoint parity on physical GPU 2, not full VLA/ManiSkill online smoke. The autonomous queue retains idle checks and never uses GPU 0/1.

## Reproduce

From this worktree and existing environment, use a new output directory:

```bash
CUDA_VISIBLE_DEVICES='' OMP_NUM_THREADS=1 python -m pytest \
  tests/unit_tests/test_atomic_decision.py tests/unit_tests/test_models.py \
  tests/unit_tests/test_data.py \
  -k 'not test_vlm_trend_batch_video_metadata_stays_nested_per_sample' -q
CUDA_VISIBLE_DEVICES='' python -m toolkits.rlt.compare_residual \
  --output "$RLT_STORAGE/research/jev_residual_new" --steps 1000 \
  --data-mode mixed --actor-start 300 --actor-lr 0.0001
RLT_ATOMIC_PROFILE=residual bash run_rlt_atomic_gpu2.sh --check
```

The final command does not train. Full pilots require explicit `--run` and existing GPU-2 occupancy checks. Next use real online collection, equal tuning budgets, fixed-start evaluation and cost accounting.
