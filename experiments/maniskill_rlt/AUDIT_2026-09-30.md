# 2026-09-30: Interaction-memory audit

This audit adds a fixed response reader to test whether the network uses available history. Attention remains the default. The [full report](https://github.com/nkd-lkz/physical-self-evolution/blob/main/research/three-branch-audit-2026-09-30.md) retains positive and negative results.

## Implementation and contract

`rlt_memory_encoder.py::response_features` estimates per-joint command/response slopes and excitation support from completed records. It masks invalid records and unexecuted action suffixes, then zero-pads to the existing 64D interface. It adds no parameters, estimates no contact force, and does not label low response as collision. Environment construction checks that normalized arm-controller bounds match `joint_delta_scale`.

The new overlay is `experiment/rlt_memory_response`. Old checkpoints receive defaults for new fields; unknown or incompatible fields remain errors.

## Experiment

Existing physical trajectories are split into 32/8/16 scene/command pairs. Both hidden PD stiffness conditions stay within one partition; hidden parameters are not model inputs. Five conditions use three initializations and 1000 updates each, with validation checkpoint selection. Test joint-change MSE: no history 0.00018211; recent 0.00018176; archive 0.00018267; full attention 0.00018143; response features plus predictor 0.00017533; direct empirical formula 0.00007389.

The last comparator has a strong structural prior and is not a parameter-matched network. History contains useful information, but learned readers remain weak. These are not task success or transfer results. Default resets clear memory, so this is not a lifelong experience store.

CPU regression: **201 passed, 1 skipped, 1 deselected**. The unrelated VideoMetadata failure also exists in baseline. The original attention path passed 20 single-rank fp32 FSDP updates and checkpoint action parity; response passed CPU policy/gradient/configuration checks but has not run full online environment training.
