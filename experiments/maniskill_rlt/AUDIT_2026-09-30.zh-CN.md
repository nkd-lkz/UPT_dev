# 2026-09-30：有限动作选择与连续修正对照

本轮补齐同幅度连续 residual，使“限制探索范围”与“离散选择”的贡献可以分开检验。[完整报告](https://github.com/nkd-lkz/physical-self-evolution/blob/main/research/three-branch-audit-2026-09-30.md)提供曲线、来源和证据限制。

## 后续：检查 critic 是否可信

合成对照新增执行动作的 Q 偏差、Q 绝对误差和双 Q 分歧指标，并支持两组使用相同的 `bc_weight`、`reference_fraction` 与种子列表。参考动作锚点是真正采样并带执行奖励的 transition，训练不读取全部候选的 oracle 标签。预先固定的下一轮网格为 BC 权重 0.1/7/70、参考样本比例 0/0.25，两种 actor 的 critic 热身和 actor 学习率一致。数据锚定问题借鉴 [DAWN](https://arxiv.org/abs/2602.10539)；当前 RLT Q head 已经包含 LayerNorm，因此这里不重复添加，也不称为论文复现。

本次 CPU 模型、数据与 atomic 测试为 205 项通过、1 项可选跳过，另排除 baseline 已有的 VideoMetadata 失败项。两种 actor 的函数空间仍不同；要求 GPU 空闲的在线队列与这些小规模离线诊断分别运行。

## 新增路径

`RLTBoundedResidualPolicy` 沿用 RLT 的 actor/critic，执行 `clip(reference + radius * tanh(raw_arm), -1, 1)`。夹爪沿用参考；确定性初始化等于已裁剪 reference。radius 写入 checkpoint 合同；entropy 权重必须为零，因为变换前 log probability 不是完整动作分布密度。

`bounded_residual` 与 `atomic_decision` 互斥，默认都不改变 baseline。新增 `RLT_ATOMIC_PROFILE=residual`，使用与 atomic pilot 相同环境、batch、更新及评估预算。两个方法具有相同每分量幅度边界，但连续 actor 可以同时修改多个关节与时间步，表达空间并不相同。

## 小实验告诉了什么

实际 RLT loss 在同一批 2048 条合成 transition 上训练，另用 256 个 context 评估。每条件三初始化、1000 critic 更新：

- 只含候选动作数据：离散最终 reward 为 0，连续约 −8.03 至 −8.25。
- 加入一半连续动作数据：结果未明显改善。
- critic 先学习 300 更新，actor LR 降至 1e-4：连续约 −3.57 至 −5.34，仍有退化。

0 是合成解析任务的最优 reward，不是机器人成功率。连续 actor 通过解析监督拟合测试，问题指向 learned critic 的梯度／数据支持和优化条件；不能用这个偏向有限候选的任务证明离散 actor 普遍更优。后两组是探索性追加，不是预注册确认实验。

CPU 回归 **204 passed、1 skipped、1 deselected**；排除项是 baseline 也失败的 VideoMetadata 依赖问题。atomic 小模型在物理 GPU 2 完成单 rank fp32 FSDP 20 次更新和恢复一致性；这不是完整 VLA／ManiSkill online smoke。自动队列继续保留空闲门槛，不会挤占 GPU 0/1。

## 追加：候选库是否包含需要执行的动作？

CPU 对照新增 `--target-mode diagonal`，要求两个关节同时修正；原单轴任务默认不变。候选库 oracle 只用于评估，actor 和 critic 仍读取相同的采样交互与实际奖励。测试证明当前候选库的解析上限为 −1，而幅度受限的连续动作可以达到 0。这诊断的是动作覆盖能力，不是学到的选择质量，也不是避碰保证。

3 个种子各训练 1000 次更新，混合动作数据、300 次 critic 热身、actor 学习率 1e-4、BC 权重 70、25% 参考动作样本，最终平均奖励为 atomic −1.1693、continuous −1.2667。两组都不能稳定达到不受候选库限制的最优值，不能据此宣称连续动作更优。这里只报告最后 checkpoint，不挑选测试表现最好的中途结果。下一步扩展候选时，应匹配参数和数据预算，并区分优化失败与候选上限。

```bash
CUDA_VISIBLE_DEVICES='' OMP_NUM_THREADS=1 python -m toolkits.rlt.compare_residual \\
  --output "$RLT_STORAGE/research/jev_diagonal_new" --steps 1000 \\
  --data-mode mixed --actor-start 300 --actor-lr 0.0001 \\
  --bc-weight 70 --reference-fraction 0.25 --target-mode diagonal
```

结果：`$RLT_STORAGE/research/jev_diagonal_20260930/results.json`；6 次 CPU 拟合，没有使用 GPU。模型／数据／atomic 回归 **206 passed、1 skipped、1 deselected**，排除项仍为已有 VideoMetadata 依赖失败。Ruff 通过。在线 policy 默认行为不变。
