## 后续：先保留已有的经验判断

`ResidualResponseProbe` 先用已完成交互估计命令响应，再加一个零初始化的学习修正项。所有诊断组都允许验证集选中第 0 步，避免训练反而丢掉更好的固定公式。先验只读取过去记录与已知控制器尺度，未来标签只用于训练监督。这是诊断读取器，不是新增在线 actor，也不代表已经学到可迁移的物理规律。

下一轮在原有配对划分上比较 6 种读取方式、6 个种子。本次 CPU 模型、数据与记忆测试为 202 项通过、1 项可选跳过，另排除 baseline 已有的 VideoMetadata 失败项。

### 追加诊断：保留已有充分支持的响应估计

已完成的 6 种子续作表明，residual 读取器降低了总体 MSE，但历史充分时仍弱于固定经验公式。因此追加 CPU 对照 `response_residual` 与 `response_supported`：用过去命令的 `1 - support` 缩放 7 个手臂关节的学习修正，手指修正保持原尺度。support 不是校准后的不确定性；条件变化后，旧估计可能支持度高却已经错误。默认读取器和生产 actor 不变。

这是看过结果后追加的探索，不混入预先声明的矩阵。仍由验证集选择 checkpoint，同时报告总体与历史充分时的误差，保留负结果；数据仍是已经查看的开发划分。

## 实现与约束

`rlt_memory_encoder.py::response_features` 从已完成记录计算每关节的命令—实际变化斜率与激励支持度，屏蔽无效记录和动作前缀，再补零到原 64 维接口。它没有新参数，不估计接触力，也不把响应小直接标成碰撞。启动环境时检查 arm controller 的归一化边界与 `joint_delta_scale` 一致。

新增 `experiment/rlt_memory_response` overlay；旧 checkpoint 缺少新字段时使用默认值恢复，未知或不兼容字段仍拒绝。

## 实验

已有真实物理轨迹按场景／命令 pair 划分 32／8／16 组，两种隐藏 PD 刚度留在同一划分，隐藏参数不作为输入。5 条件 × 3 初始化 × 1000 更新，按验证集选权重。测试变化 MSE：无历史 0.00018211，近期 0.00018176，archive 0.00018267，attention 全历史 0.00018143，响应特征＋预测头 0.00017533，直接固定响应公式 0.00007389。

最后一项有明确结构先验，不是同容量网络。结论是历史有可用信息，但当前学习式读取仍偏弱；不是任务成功或跨任务迁移结果。默认 reset 清空记忆，当前不等于终身经验库。

CPU 回归 **201 passed、1 skipped、1 deselected**；无关 VideoMetadata 错误在 baseline 也存在。单 rank fp32 FSDP 的原 attention 路径通过 20 次更新及权重动作一致性；新 response 路径已通过 CPU policy、梯度和配置检查，尚未做完整环境在线训练。

## 追加：旧经验也会误导下一次判断

`response_features(..., record_weights=...)` 增加有限、非负的历史记录权重，默认数值行为保持一致。CPU 诊断 `toolkits.rlt.probe_response_shift` 比较均匀历史、三种固定遗忘速度和自适应清理：连续两次已观察到的预测误差超过 0.015 关节变化单位后，只保留最新两条记录，供下一次判断使用。这是诊断规则，尚未启用到在线 actor。

6 个配对种子覆盖稳定、响应减弱、响应增强三种合成条件，共 90 条数据流，不是 90 个训练模型或机器人试验。固定快速遗忘加快适应，却让稳定条件后段 MSE 从 4.65e-6 增加到 1.12e-5。后续自适应规则保持稳定条件 MSE 为 4.65e-6，响应减弱后前 8 步的 MSE 从 6.96e-4 降至 3.34e-4；响应增强时从 7.36e-4 降至 3.58e-4。发生变化的所有数据流都在观察到第 61 个 tick 后清理旧记录，稳定流没有触发。变化瞬间的激励 support 约为 0.993，说明它不能称为置信度。这类理想突变不证明检测到了摩擦或接触，也不验证真机阈值。

自适应规则是在查看固定遗忘结果后追加的探索，不是独立确认；此前的 72 条流报告保留。使用新目录复查：

```bash

  --output "$RLT_STORAGE/research/zeva_retention_new"
```

结果：`$RLT_STORAGE/research/zeva_retention_adaptive_20260930/results.json`。模型／数据／记忆 CPU 回归 **206 passed、1 skipped、1 deselected**，排除项仍为已有 VideoMetadata 依赖失败。Ruff 通过。本轮没有使用 GPU 或改变生产控制配置。
